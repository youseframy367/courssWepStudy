# مراجع بناء الكتب التفصيلية

يستخدم محتوى مكتبة الكتب شرحاً أصلياً باللغة العربية وأمثلة قصيرة مكتوبة خصيصاً للمنصة. المراجع التالية تُستخدم فقط لضبط **تسلسل التعلم** وإضافة روابط متابعة موثوقة؛ لا يُنسخ منها محتوى محمي أو أسئلة أو مشاريع كاملة.

| المسار | ترتيب الموضوعات المسترشد به | المرجع الرسمي |
|---|---|---|
| HTML وCSS وJavaScript | البدء، بناء المحتوى، التنسيق، السلوك، ثم التحديات المتدرجة | [MDN Learn web development](https://developer.mozilla.org/en-US/docs/Learn_web_development) |
| Node.js وNest | الإعداد، سطر الأوامر، HTTP، الملفات، async، الاختبار، والأمان | [Node.js Learn](https://nodejs.org/learn) |
| Dart وFlutter | الإعداد، Dart، Widgets، layout، state، الشبكات، والاختبار | [Flutter learning pathway](https://docs.flutter.dev/learn/pathway) و[Learn Dart](https://dart.dev/learn) |

> تظل الروابط الخارجية اختيارية وتفتح في تبويب جديد، بينما يظل المحتوى المعروض داخل الموقع من صياغة أصلية ومختصرة أو تفصيلية حسب الكتاب.
