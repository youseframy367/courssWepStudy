# المراجعة البصرية

## الصفحة الرئيسية — سطح المكتب

- ظهرت الهوية الداكنة للرأس، شريط الكورسات، القسم التعليمي، مسار Frontend، المصادر الأصلية، التدريب العملي، أدوات الألوان والخطوط والأيقونات، محرر الكود، والفوتر مع واجهة محادثة AI.
- روابط المصادر المعروضة تشير إلى المصادر الأصلية بدلاً من نسخ محتواها داخل الموقع.
- يظهر قسم التمارين حالة تحميل عندما لا تكون خدمة NestJS متاحة للواجهة؛ وهذا سلوك آمن متوقع في المعاينة الحالية لأن خادم API لم يُشغّل مع المتغير العام للرابط.
- المراجعة التالية: اختبار ستارة اختيار المجال، صفحة تفاصيل كورس، وتشغيل API محلياً قبل الرفع.

## التفاعل والمسارات

اختبار زر **مجالات المذاكرة** أظهر ستارة في أعلى الصفحة تحتوي على Frontend وBackend وFlutter & Dart وProblem Solving. اختيار Backend أغلق الستارة، ونقل العرض إلى مسار Backend، وبدّل المصادر والروابط التدريبية إلى موارد Node.js وExpress وNestJS وHackerRank وPostman. تم كذلك التحقق من أن وكيل Next.js يعيد بيانات التمارين من NestJS عبر المسار المحلي `/learning-api/study-domains/backend/challenges` بنجاح.
