# مصادر مسارات المذاكرة

هذا الملف يوثق روابط المصادر التي ستظهر كروابط خارجية داخل المنصة. لا يتم نسخ الدروس أو المسائل من هذه المواقع؛ تعرض المنصة ملخصاً موجزاً ومؤلفاً داخلياً مع رابط واضح إلى المصدر الأصلي.

| المجال | المصدر | الاستخدام داخل المنصة | الرابط |
|---|---|---|---|
| Frontend | MDN Learn Web Development | مسار البداية، HTML، CSS، JavaScript، واختبارات فهم قصيرة | https://developer.mozilla.org/en-US/docs/Learn_web_development |
| Frontend | freeCodeCamp Responsive Web Design | تمارين HTML/CSS ومشروعات تطبيقية متدرجة | https://www.freecodecamp.org/learn/responsive-web-design-v9 |
| Frontend | Frontend Mentor Challenges | مشروعات واجهات عملية حسب المستوى | https://www.frontendmentor.io/challenges |
| Backend | Node.js Learn | أساسيات تشغيل JavaScript على الخادم، HTTP، وCLI | https://nodejs.org/learn |
| Backend | MDN Express/Node introduction | شرح مفاهيم Node.js وExpress كبداية منظمة | https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Server-side/Express_Nodejs/Introduction |
| Backend | Express | مرجع الإطار وروابط البدء الرسمية | https://expressjs.com/ |
| Flutter | Flutter Learning Pathway | مسار بداية متدرج: إعداد البيئة، Dart، ثم بناء تطبيقات Flutter | https://docs.flutter.dev/learn/pathway |
| Flutter | Learn Dart | أساسيات Dart مع درس تطبيقي للمبتدئين | https://dart.dev/learn |
| Flutter | Flutter Learning Resources | Codelabs وأمثلة وتطبيقات ومواد تدريبية رسمية | https://docs.flutter.dev/reference/learning-resources |
| Algorithms | HackerRank Problem Solving | روابط لمسائل مرتبة حسب الصعوبة | https://www.hackerrank.com/domains/algorithms |
| Algorithms | LeetCode Algorithms | روابط لمسائل خوارزميات ومقابلات تقنية | https://leetcode.com/problemset/algorithms/ |

## سياسة الاستخدام

تُحفظ عناوين المصادر والرابط والتصنيف والمستوى داخل البيانات المحلية أو عبر API. يُفتح كل رابط خارجي في تبويب جديد مع `noopener noreferrer`. لا تعتمد المنصة على كشط المحتوى أو استيراد نصوص أو أسئلة محمية بحقوق نشر من مصدر خارجي.
