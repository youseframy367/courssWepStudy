# Course Web Study

نسخة **Next.js** منظمة لمنصة تعليمية لشرح تقنيات تطوير الويب، مع الحفاظ على الواجهة العملية الداكنة وشريط التخصصات وتجربة قراءة الدروس.

## التقنيات

| العنصر | الاستخدام |
| --- | --- |
| Next.js 15 | App Router ومسارات الدروس الديناميكية |
| React 19 | المكونات والتفاعلات داخل الواجهة |
| TypeScript | تنظيم البيانات والتحقق من الأنواع |
| Tailwind CSS 4 | طبقة التنسيقات العامة |
| Lucide | الأيقونات الخفيفة والمتسقة |

## المسارات

- `/` الصفحة الرئيسية: البحث، شريط الكورسات، وأدوات الألوان والخطوط والأيقونات.
- `/course/[slug]` صفحة الدرس الديناميكية، مثل `/course/html` و`/course/javascript`.

بيانات الكورسات والدروس مركزية في `app/lib/courses.ts`، والمكونات القابلة لإعادة الاستخدام موجودة في `app/components/`.

## التشغيل محلياً

```bash
pnpm install
pnpm dev
```

## التحقق قبل النشر

```bash
pnpm check
pnpm build
```

أمر البناء يضبط `NODE_ENV=production` لضمان أن فحص الإنتاج يعمل بنفس الصورة في البيئة المحلية والاستضافة.
